# (Restaurant System) example Backend

Example Backend

# Requirement

- .NET 10
- Visual Studio 2026
- C# 14

# Run the project

## Visual Studio 2026

- Clean and Build
    1. Go to Build Menu > Clean Solution 
    2. Go to Build Menu > Build Solution

- press F5 to debug project

## Terminal
1. Clean and build
    ```sh
    dotnet clean --project xxx --startup-project xxx
    dotnet build --project xxx --startup-project xxx
    ```
2. debug project
     ```sh
    dotnet run --project xxx --startup-project xxx
    ```
